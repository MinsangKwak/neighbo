# 09 · 마이페이지

[문서 목차](../README.md) · 앞: [08 · 채팅](08-chat.md) · 다음: [10 · 채팅 알림](10-notification.md) · 설계: [흐름](../architecture/flow.md) · [프론트엔드](../architecture/frontend.md) · [백엔드](../architecture/backend.md)

**마이페이지는 내 정보, 상태별 판매 목록, 구매 내역을 확인하고 프로필·비밀번호를 변경하는 화면입니다.** 닉네임·아바타 변경과 로그아웃을 포함하며, 구매 내역에는 거래완료 시 지정된 구매자와 거래 시점 정보를 반영합니다.

## 요구사항

**유저 스토리** — 사용자로서, 내가 올린 물건을 상태별로 보고, 산 물건을 확인하고, 닉네임 · 사진 · 비밀번호를 바꾸고 싶다.

**권한** — 로그인. `PATCH /me`는 닉네임 · 아바타만 허용(화이트리스트).
