# 03 · 중고 목록

[문서 목차](../README.md) · 앞: [02 · 로그인 · 로그아웃](02-login.md) · 다음: [04 · 거래 등록 · 수정](04-product-create.md) · 설계: [흐름](../architecture/flow.md) · [프론트엔드](../architecture/frontend.md) · [백엔드](../architecture/backend.md)

**중고 목록은 삭제되지 않은 상품을 최신 등록순으로 보여주는 홈 화면입니다.** 카드를 선택하면 상세로 이동하며, 1차 검색 범위는 제목입니다. 카테고리와 정렬 변경은 후속 범위로 분리했습니다.

## 요구사항

**유저 스토리** — 누구든(비로그인 포함), 동네에 올라온 물건을 최신순으로 훑어보고 마음에 드는 것을 눌러 자세히 보고 싶다.

**권한** — 비로그인 열람 가능 [결정 0011]. 등록 버튼은 로그인 필요.
