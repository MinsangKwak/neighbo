# 02 · 로그인 · 로그아웃

[문서 목차](../README.md) · 앞: [01 · 회원가입](01-signup.md) · 다음: [03 · 중고 목록](03-product-list.md) · 설계: [흐름](../architecture/flow.md) · [프론트엔드](../architecture/frontend.md) · [백엔드](../architecture/backend.md)

**로그인은 이메일·비밀번호를 확인한 뒤 httpOnly 쿠키를 발급하는 흐름입니다.** 이후 요청은 쿠키로 인증하고, 로그아웃 시 쿠키를 삭제합니다. 입력 오류와 세션 만료 등의 기대 동작은 아래 표에 정리했습니다.

## 요구사항

**유저 스토리** — 가입한 사람으로서, 이메일 · 비밀번호로 들어가서 7일 동안은 다시 묻지 않았으면 한다. 끝나면 로그아웃하고 싶다.

**권한** — 로그인: 비로그인만. 로그아웃: 로그인만.

## 경우의 수

**로그인은 이메일·비밀번호를 확인한 뒤 httpOnly 쿠키를 발급하는 흐름입니다.** 이후 요청은 쿠키로 인증하고, 로그아웃 시 쿠키를 삭제합니다. 입력 오류와 세션 만료 등의 기대 동작은 아래 표에 정리했습니다.

### 정상

| ID | 상황 | 기대 동작 (제안) | 결정 |
| --- | --- | --- | --- |
| LI-OK-01 | 올바른 이메일 · 비밀번호 | `200` + 쿠키. 홈으로, `?next=`가 있으면 거기로 (→ CM-AU-01). 토스트 없음 | — |
| LI-OK-02 | 이메일 대소문자 다르게 입력 | 소문자 정규화 후 비교 → 성공 | — |
| LI-OK-03 | 로그인 후 헤더 | 아바타 · 닉네임 표시, 채팅 배지(NT 문서) 즉시 조회 | — |
| LI-OK-04 | 새로고침 | 쿠키로 자동 인증. 서버 컴포넌트에서 사용자 조회 → 로그인 상태로 첫 렌더 (깜빡임 없음) | — |
| LI-OK-05 | 브라우저 닫았다 다시 열기 | 쿠키 `Max-Age` 안이면 유지 (세션 쿠키 아님) | — |
| LI-OK-06 | Enter로 제출 | 가능 | — |
| LI-OK-07 | 브라우저 자동완성 | `autocomplete`: `email` · `current-password` | — |
