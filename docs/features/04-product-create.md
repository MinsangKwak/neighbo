# 04 · 거래 등록 · 수정

[문서 목차](../README.md) · 앞: [03 · 중고 목록](03-product-list.md) · 다음: [05 · 거래 상세 · 상태 변경](05-product-detail.md) · 설계: [흐름](../architecture/flow.md) · [프론트엔드](../architecture/frontend.md) · [백엔드](../architecture/backend.md)

**거래 등록·수정은 제목·가격·설명·사진을 입력하는 공통 폼을 사용합니다.** 수정 시에는 기존 사진 삭제가 추가됩니다. 사진은 [선택 즉시 업로드](../decisions.md#0010--사진은-선택-즉시-업로드하고-등록은-url만-보낸다)하며, 거래 수정의 범위는 [결정 0013](../decisions.md#0013--거래-수정을-1차-범위에-넣는다)에 정리했습니다.

## 요구사항

**유저 스토리** — 판매자로서, 사진 몇 장과 제목 · 가격 · 설명으로 1분 안에 물건을 올리고, 나중에 오타나 가격을 고치고 싶다.

**권한** — 등록: 로그인. 수정: 작성자만 (화면 404 · API 403) [PC-AU-03].
