# 05 · 거래 상세 · 상태 변경

[문서 목차](../README.md) · 앞: [04 · 거래 등록 · 수정](04-product-create.md) · 다음: [06 · 거래 삭제](06-product-delete.md) · 설계: [흐름](../architecture/flow.md) · [프론트엔드](../architecture/frontend.md) · [백엔드](../architecture/backend.md)

**거래 상세에서 구매자는 상품 정보를 확인하고 채팅을 시작하며, 판매자는 상품과 거래 상태를 변경합니다.** 아래 상태 전이 표는 요청자와 현재 상태별로 허용할 변경을 정의합니다.

## 요구사항

**유저 스토리** — 구매자로서, 물건의 사진 · 설명 · 상태를 보고 바로 채팅을 걸고 싶다. 판매자로서, 내 물건의 상태를 바꾸고 누구와 거래했는지 남기고 싶다.

**권한** — 열람: 누구나 [결정 0011]. 상태 변경 · 수정 · 삭제: 판매자만. [채팅하기]: 로그인한 비판매자만.

### 상태 전이 (제안)

| 현재 \ 행위 | 예약중으로 | 거래완료로 | 판매중으로 | 누가 |
| --- | --- | --- | --- | --- |
| **판매중** | ✅ | ✅ | — | 판매자 |
| **예약중** | — | ✅ | ✅ (예약 취소) | 판매자 |

- 상태 변경은 **판매자만.** 구매자는 어떤 상태도 바꿀 수 없다.
- 거래완료 → 예약중은 막는다. 완료를 되돌리려면 판매중으로.
- 거래완료 시 **구매자 지정**: 채팅 중인 상대 목록에서 선택(선택 안 함도 가능). 지정하면 `buyerId · soldAt` 저장. 1차에 포함 — [결정 0012](../decisions.md#0012--거래완료-시-구매자를-지정하고-구매-내역을-둔다).
- 거래완료 → 판매중 복귀 시 `buyerId · soldAt`은 `null`로.
- 삭제된 상품은 어떤 전이도 불가.
