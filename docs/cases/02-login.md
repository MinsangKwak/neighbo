# LI · 로그인 · 로그아웃 · 세션 유지

[경우의 수 목차](README.md) · 공통: [00-common.md](00-common.md) · 앞: [01-signup.md](01-signup.md)

**이메일 · 비밀번호로 로그인하면 httpOnly 쿠키가 발급되고, 이후 모든 요청은 쿠키로 인증합니다.** 로그아웃은 쿠키를 지웁니다.

## 정상

| ID | 상황 | 기대 동작 (제안) | 결정 |
| --- | --- | --- | --- |
| LI-OK-01 | 올바른 이메일 · 비밀번호 | `200` + 쿠키. 홈으로, `?next=`가 있으면 거기로 (→ CM-AU-01). 토스트 없음 | — |
| LI-OK-02 | 이메일 대소문자 다르게 입력 | 소문자 정규화 후 비교 → 성공 | — |
| LI-OK-03 | 로그인 후 헤더 | 아바타 · 닉네임 표시, 채팅 배지(NT 문서) 즉시 조회 | — |
| LI-OK-04 | 새로고침 | 쿠키로 자동 인증. 서버 컴포넌트에서 사용자 조회 → 로그인 상태로 첫 렌더 (깜빡임 없음) | — |
| LI-OK-05 | 브라우저 닫았다 다시 열기 | 쿠키 `Max-Age` 안이면 유지 (세션 쿠키 아님) | — |
| LI-OK-06 | Enter로 제출 | 가능 | — |
| LI-OK-07 | 브라우저 자동완성 | `autocomplete`: `email` · `current-password` | — |

## 로그아웃

| ID | 상황 | 기대 동작 (제안) | 결정 |
| --- | --- | --- | --- |
| LI-LO-01 | 로그아웃 버튼 위치 | 마이페이지 하단. 헤더에는 두지 않음 | — |
| LI-LO-02 | 로그아웃 클릭 | 확인 없이 즉시. `POST /auth/logout` → 쿠키 삭제 → 홈으로. 토스트 "로그아웃했어요" | — |
| LI-LO-03 | 로그아웃 후 뒤로가기 | 캐시된 보호 화면이 보이면 안 됨. 보호 화면은 `Cache-Control: no-store`, 클라이언트 캐시(TanStack Query) 전체 초기화 | — |
| LI-LO-04 | 로그아웃 후 소켓 연결 | 즉시 `disconnect`. 알림 배지 0으로 | — |
| LI-LO-05 | 로그아웃 API 실패 | 쿠키는 클라이언트에서도 지울 수 없음(httpOnly). 토스트 "다시 시도해 주세요" | — |
| LI-LO-06 | 두 탭 중 한 탭에서 로그아웃 | 다른 탭은 다음 요청에서 `401` → 로그인 화면. 즉시 반영 원하면 `storage` 이벤트로 신호 | — |
| LI-LO-07 | 다른 기기 모두 로그아웃 | 1차 불가 (stateless JWT) | ⛔ |

## 세션 · 토큰

| ID | 상황 | 기대 동작 (제안) | 결정 |
| --- | --- | --- | --- |
| LI-TK-01 | 쿠키 속성 | `HttpOnly; Secure; SameSite=Lax; Path=/; Max-Age=7d` → [결정 0003](../decisions/0003-jwt-httponly-cookie.md) | — |
| LI-TK-02 | 프론트(Vercel)와 백엔드(Railway) 도메인이 다름 | Next.js Route Handler로 API를 프록시해 같은 오리진 유지. 소켓 연결의 쿠키 전달은 기술 노트에서 검증 후 확정 → [결정 0004](../decisions/0004-api-proxy-same-origin.md) | — |
| LI-TK-03 | 토큰 페이로드 | `sub(userId), iat, exp`만. 닉네임 등은 넣지 않음(변경 시 불일치) | — |
| LI-TK-04 | 토큰 갱신 | 요청마다 남은 기간이 절반 이하면 새 쿠키 발급(슬라이딩). 리프레시 토큰 없음 → [결정 0003](../decisions/0003-jwt-httponly-cookie.md) | — |
| LI-TK-05 | 비밀번호 변경 후 기존 토큰 | `User.tokenVersion`을 올리고 토큰에 포함해 과거 토큰 무효화. 1차 포함 → [결정 0003](../decisions/0003-jwt-httponly-cookie.md) | — |
| LI-TK-06 | 서버 컴포넌트에서 사용자 조회 실패 (백엔드 다운) | 비로그인 상태로 렌더하지 않고 → CM-NW-01 에러 상태 | — |
| LI-TK-07 | 소켓 연결의 인증 | 같은 쿠키를 핸드셰이크에서 검증. 만료면 `connect_error` → 재로그인 유도 | — |
