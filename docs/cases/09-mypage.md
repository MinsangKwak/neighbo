# MP · 마이페이지

[경우의 수 목차](README.md) · 공통: [00-common.md](00-common.md)

**내 정보를 보고, 내가 올린 물건을 상태별로 보고, 닉네임을 바꾸고, 로그아웃합니다.** 00 개요에 "프로필 사진 변경은 2차"로 되어 있지만 이 문서에서 다시 묻습니다 — 업로드 파이프라인이 거래 등록에서 이미 생기므로 비용이 낮습니다.
