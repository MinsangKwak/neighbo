# PL · 중고 목록

[경우의 수 목차](README.md) · 공통: [00-common.md](00-common.md)

**홈 화면입니다. 삭제되지 않은 상품을 최신 등록순으로 보여주고, 카드를 누르면 상세로 갑니다.** 검색은 제목 검색 하나, 카테고리 · 정렬 변경은 1차에 없습니다.
