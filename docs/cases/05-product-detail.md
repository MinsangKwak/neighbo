# PD · 거래 상세 · 거래 상태 변경

[경우의 수 목차](README.md) · 공통: [00-common.md](00-common.md)

**거래 상세에서 구매자는 상품 정보를 확인하고 채팅을 시작하며, 판매자는 상품과 거래 상태를 변경합니다.** 아래 상태 전이 표는 요청자와 현재 상태별로 허용할 변경을 정의합니다.

## 상태 전이 (제안)

| 현재 \ 행위 | 예약중으로 | 거래완료로 | 판매중으로 | 누가 |
| --- | --- | --- | --- | --- |
| **판매중** | ✅ | ✅ | — | 판매자 |
| **예약중** | — | ✅ | ✅ (예약 취소) | 판매자 |
| **거래완료** | ❌ | — | ✅ (완료 취소) | 판매자 |

- 상태 변경은 **판매자만.** 구매자는 어떤 상태도 바꿀 수 없다.
- 거래완료 → 예약중은 막는다. 완료를 되돌리려면 판매중으로.
- 거래완료 시 **구매자 지정**: 채팅 중인 상대 목록에서 선택(선택 안 함도 가능). 지정하면 `buyerId · soldAt` 저장. 1차에 포함 — [결정 0012](../decisions/0012-buyer-assignment.md).
- 거래완료 → 판매중 복귀 시 `buyerId · soldAt`은 `null`로.
- 삭제된 상품은 어떤 전이도 불가.

| ID | 상황 | 기대 동작 (제안) | 결정 |
| --- | --- | --- | --- |
| PD-TR-01 | 위 표에 없는 전이 요청 (예: 완료 → 예약) | `409 INVALID_TRANSITION`, `message: "거래완료 상태에서는 예약중으로 바꿀 수 없어요"` | — |
| PD-TR-02 | 같은 상태로 변경 (판매중 → 판매중) | `200`, 변경 없음 (멱등) | — |
| PD-TR-03 | 상태 변경 UI | 판매자에게만 상단에 상태 드롭다운 (`<select>`) 또는 바텀시트. 선택 즉시 `PATCH /products/{id}/status` | — |
| PD-TR-04 | 거래완료 선택 시 | 바텀시트 "누구와 거래했나요?" 채팅 상대 목록 + "선택 안 함". 채팅 상대가 0명이면 바로 완료 → [결정 0012](../decisions/0012-buyer-assignment.md) | — |
| PD-TR-05 | 거래완료 취소 (→ 판매중) | 확인 모달 "거래완료를 취소할까요? 구매자 정보가 지워져요" | — |
| PD-TR-06 | 예약 취소 (→ 판매중) | 확인 없이 즉시 | — |
| PD-TR-07 | 상태 변경 후 채팅 상대에게 알림 | 1차 없음. 채팅방 상단 요약이 다음 조회에서 바뀜 | — |
| PD-TR-08 | 거래완료 후 N일 뒤 자동 잠금 | 없음 | ⛔ |
| PD-TR-09 | 예약자 지정 (예약중 → 누구와) | 1차 없음. 예약중은 상대 없는 상태 | — |
