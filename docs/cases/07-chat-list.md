# CL · 채팅 목록

[경우의 수 목차](README.md) · 공통: [00-common.md](00-common.md)

**채팅 목록은 참여 중인 방을 마지막 메시지 시각의 역순으로 보여줍니다.** 각 행에는 상대 정보, 상품 썸네일, 마지막 메시지, 시각, 읽지 않은 메시지 수를 표시합니다. 새 메시지와 읽음 상태에 따른 갱신은 알림 명세와 연결됩니다.
