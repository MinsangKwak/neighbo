# PC · 거래 등록 (· 수정)

[경우의 수 목차](README.md) · 공통: [00-common.md](00-common.md)

**제목 · 가격 · 설명 · 사진으로 상품을 올립니다.** 거래 수정은 1차 범위에 포함하기로 했습니다([결정 0013](../decisions/0013-edit-in-scope.md)) — 등록 폼을 그대로 재사용하되 기존 사진 삭제가 추가됩니다. 사진은 선택 즉시 업로드합니다([결정 0010](../decisions/0010-upload-on-select.md)).

## 정상

| ID | 상황 | 기대 동작 (제안) | 결정 |
| --- | --- | --- | --- |
| PC-OK-01 | 로그인 상태로 `+` 진입 | 등록 화면 `/products/new`. 필드: 사진(0~10장) · 제목 · 가격 · 나눔 토글 · 설명. 상단 [취소] · 하단 [등록하기] | — |
| PC-OK-02 | 모두 채우고 등록 | 사진 먼저 업로드 → 상품 생성 `201` → 상세 화면으로 `replace`. 토스트 "물건을 올렸어요" | — |
| PC-OK-03 | 등록 순서 (사진 업로드 시점) | **선택 즉시 업로드** (`POST /uploads` → URL 반환, 미리보기 표시). 등록 버튼은 URL 목록만 전송. 고아 파일은 배치로 정리 (→ PC-DT-12) → [결정 0010](../decisions/0010-upload-on-select.md) | — |

| PC-OK-05 | 초기 상태 | 상태는 항상 `판매중`으로 생성. 등록 시 상태 선택 없음 | — |
| PC-OK-06 | 등록 후 돌아가기 | 상세 → 뒤로가기 → 홈(등록 화면 건너뜀) | — |
| PC-OK-07 | 입력 중 이탈 (뒤로 · 탭 닫기 · 다른 링크) | 내용이 하나라도 있으면 확인 모달 "작성 중인 내용이 사라져요. 나갈까요?" (`beforeunload` + 라우터 가드) | — |
| PC-OK-08 | 작성 중 내용 임시 저장 | 1차 없음. CM-AU-03과 함께 결정 | — |
