# SU · 회원가입

[경우의 수 목차](README.md) · 공통: [00-common.md](00-common.md)

**이메일 · 비밀번호 · 비밀번호 확인 · 닉네임 네 칸으로 가입하고, 성공하면 바로 로그인 상태가 됩니다.** 이메일 인증 메일은 보내지 않습니다(1차).

## 정상

| ID | 상황 | 기대 동작 (제안) | 결정 |
| --- | --- | --- | --- |
| SU-OK-01 | 네 칸을 모두 올바르게 채우고 제출 | `201` + 쿠키 발급. 토스트 "환영해요, {닉네임}님" 후 홈으로. `?next=`가 있으면 거기로 | — |
| SU-OK-02 | 가입 직후 상태 | 상품 0개, 채팅방 0개, 아바타는 기본 이미지 | — |
| SU-OK-03 | 입력 중 실시간 검증 | 필드를 떠날 때(`blur`) 검증, 오류가 있던 필드는 입력마다 재검증. 제출 전까지 서버 호출 없음 (이메일 중복은 예외 → SU-IN-10) | ❓ |
| SU-OK-04 | 제출 버튼 활성 조건 | 항상 활성. 누르면 전체 검증 후 첫 오류로 포커스. (비활성 버튼은 "왜 안 눌리는지" 모르는 접근성 문제) | — |
| SU-OK-05 | Enter 키로 제출 | 마지막 칸이 아니어도 Enter로 제출 | — |

## 입력 — 이메일

| ID | 상황 | 기대 동작 (제안) | 결정 |
| --- | --- | --- | --- |
| SU-IN-01 | 비어 있음 | "이메일을 입력해 주세요" | — |
| SU-IN-02 | `@` 없음 · 도메인 없음 · 공백 포함 | "이메일 형식이 아니에요". 검증은 HTML5 `type=email` 수준의 정규식 하나를 프론트 · 서버가 공유 | — |
| SU-IN-03 | 대문자 포함 (`Kim@Example.com`) | 소문자로 정규화해 저장 · 비교. 화면에는 입력한 대로 표시 | — |
| SU-IN-04 | 앞뒤 공백 | `trim` 후 검증 (→ CM-DT-11) | — |
| SU-IN-05 | 255자 초과 | "이메일이 너무 길어요" (최대 254자) | — |
| SU-IN-06 | 한글 도메인 · 국제화 이메일 | 1차는 ASCII만 허용. "영문 이메일만 사용할 수 있어요" | ❓ |
| SU-IN-07 | `+` 태그 (`kim+test@gmail.com`) | 허용. 별도 계정으로 취급 | — |
| SU-IN-08 | 일회용 메일 도메인 | 차단하지 않음 | — |
| SU-IN-09 | 이미 가입된 이메일로 제출 | `409 EMAIL_TAKEN`. 필드 오류 "이미 가입된 이메일이에요. [로그인하기]" (링크 포함) | — |
| SU-IN-10 | 이메일 칸을 떠날 때 중복 미리 확인 | `GET /auth/email-available?email=` 호출해 즉시 안내. 단, 이 API는 계정 존재 여부를 노출하므로 rate limit(CM-SEC-04) 적용 | ❓ |
| SU-IN-11 | 중복 확인 API가 실패 | 조용히 넘어가고 제출 시 서버 검증에 맡김 | — |

## 입력 — 비밀번호

| ID | 상황 | 기대 동작 (제안) | 결정 |
| --- | --- | --- | --- |
| SU-IN-20 | 비어 있음 | "비밀번호를 입력해 주세요" | — |
| SU-IN-21 | 8자 미만 | "8자 이상 입력해 주세요" | ❓ 최소 길이 |

| SU-IN-25 | 이메일과 동일 · 닉네임 포함 | "이메일이나 닉네임과 같은 비밀번호는 쓸 수 없어요" | ❓ |
| SU-IN-26 | 비밀번호 보기 토글 | 눈 아이콘 버튼, `aria-label="비밀번호 보기"/"숨기기"`, `aria-pressed` | — |
| SU-IN-27 | 비밀번호 확인 칸이 다름 | "비밀번호가 일치하지 않아요". 확인 칸에 표시. 원본 칸을 고치면 확인 칸도 재검증 | — |
| SU-IN-28 | 비밀번호 확인 칸 자체가 필요한가 | 제안: 둔다. 보기 토글이 있어도 모바일 자동완성 오타가 잦음 | ❓ |
| SU-IN-29 | 브라우저 비밀번호 생성기 사용 | `autocomplete="new-password"` 지정해 생성기가 뜨게 | — |
| SU-IN-30 | 유니코드 비밀번호 (한글 · 이모지) | 허용. NFC 정규화 후 해시 | — |
