# PX · 거래 삭제

[경우의 수 목차](README.md) · 공통: [00-common.md](00-common.md) · 앞: [05-product-detail.md](05-product-detail.md)

**작성자가 자기 상품을 내립니다. 항상 soft delete(`deletedAt` 기록)이며, 삭제 하나가 목록 · 상세 · 채팅 목록 · 채팅방 · 마이페이지 다섯 화면에 영향을 줍니다.** 이 문서는 "삭제된 상품"이 각 화면에서 어떻게 보이는지를 전부 적습니다.

## 삭제 규칙 (제안)

| 질문 | 제안 | 결정 |
| --- | --- | --- |
| 하드 삭제를 하는 경우가 있는가 | 없다. 채팅방 유무와 관계없이 항상 soft. (00 개요의 "채팅방이 있으면 soft"를 "항상 soft"로 단순화 — 분기가 하나 줄고, 실수로 지운 글 복구 여지가 생김) | ❓ |
| 어느 상태에서 삭제 가능한가 | 판매중 · 예약중 · 거래완료 모두 가능 | ❓ 거래완료 삭제 허용 |
| 삭제 후 복구 | 1차 UI 없음. DB에서만 가능 | ⛔ |
| 삭제된 상품의 채팅방 | 열람 가능 · **메시지 전송 불가**. 상단에 "삭제된 물건이에요" 안내 | ❓ |
| 파일 삭제 | soft delete 시 파일 유지. 30일 후 배치로 파일 · 이미지 행 삭제 (상품 행은 유지) | ❓ |
