# 검토 요청 · 확인이 필요한 판단

[문서 목차](README.md)

**작업 중 확인을 받지 못한 채 내린 판단을 모아 둡니다.** 각 행은 "고른 답"대로 이미 반영되어 있습니다. 뒤집을 행이 있으면 번호로 알려주면 해당 문서와 함께 고칩니다. 확인이 끝난 행은 "확인" 열에 날짜를 적고, 다 확인되면 이 문서는 비웁니다.
