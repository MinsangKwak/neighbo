# 문서 목차

**문서는 기능별 요구사항 11장, 설계 3장(흐름 · 프론트엔드 · 백엔드), 기록 4장으로 나뉩니다.** 처음이라면 개요 → 흐름 설계 → 궁금한 기능 문서 순서로 읽으면 됩니다. 기능 하나에 필요한 요구사항 · 경우의 수는 그 기능 문서 한 장에 모여 있고, 여러 기능에 걸친 처리 방식은 설계 문서에 있습니다.

## 문서 간 연결

수용 조건은 같은 문서의 경우의 수 ID(`CH-CC-07` 등)를, 설계는 수용 조건 번호(`AC-CH-05` 등)를 참조합니다. 문서를 고친 뒤에는 `python3 scripts/check-docs.py`로 링크 · 앵커 · 표를 검사합니다.
